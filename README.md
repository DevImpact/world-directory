# DevImpact — World Directory

The public catalogue of discoverable projects in the DevImpact ecosystem.

**Main website:** https://devimpact.github.io/

## Browse projects

**Directory URL:** https://devimpact.github.io/world-directory/

The directory is hosted as a GitHub Pages project site from this repository's `main` branch and root folder. If the site is not yet available, check the repository's **Settings → Pages** and allow the Pages deployment to finish. You can also browse the catalogue directly in [index.html](./index.html).

The structured catalogue is available in [projects.json](./projects.json).

## Categories

- **Mobile apps:** Job Connect; Célibataire: Rencontres & Chat.
- **Mobile games:** Tetrixa; Fruit Fury Slice; Bubble Fury; Nextube.
- **Developer tools:** Blogger Auto Publisher.
- **Browser extensions:** Bluesky Follow Assistant.

## Directory policy

- Entries link to public project repositories and, where verified in their project documentation, official websites and Google Play listings.
- Product descriptions are intentionally brief and based on each project's available README/store-sourced scope.
- This public directory does not expose private repositories, credentials, internal plans or unpublished projects.
- Repositories that appear to be template/duplicate copies with stale Job Connect documentation are not listed as separate products.
- A missing store or website link means no verified public link is listed here; it does not imply the project has no such presence.

## Updating the catalogue

Update `projects.json` and the project cards in `index.html` together. Keep links accurate and descriptions aligned with the relevant public project documentation and official store listing.
